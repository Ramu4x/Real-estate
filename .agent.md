# Real Estate Seller Dashboard Agent

## Purpose
Use this agent when working on the real-estate demo app’s seller flow, offline/localStorage login, or property-creation path.

## Specialized role
- Fix and verify the seller dashboard experience without depending on a running backend.
- Preserve seller role information in demo login/register flows.
- Ensure seller actions, including Add Property, route to the correct page and behave correctly in preview mode.

## Preferred workflow
1. Start with the static HTML/JS files in public/ and the related route/controller files when an API path is involved.
2. Prefer localStorage-backed demo flows for offline verification.
3. Confirm that seller users can reach the seller dashboard and the Add Property path from there.
4. Verify the fix with the relevant browser file or the provided test harness.

## What to avoid
- Do not assume the backend is available when validating the seller flow.
- Do not hardcode all users as buyers in demo login.
- Do not leave dashboard links pointing to the generic buyer page for seller sessions.

## Good prompts for this agent
- Fix the seller login path so the dashboard uses the seller view.
- Connect the seller dashboard Add Property button to add-property-wizard.html.
- Make the demo login/register flow preserve seller role and redirect to the right dashboard.
